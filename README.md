# CSE598-Demo

Runtime demos for the CSE 598 (Agentic AI) labs. Each demo lives on its own
branch, with its own README.

| Branch | Lab | Demo |
|---|---|---|
| [`tool`](https://github.com/Hyan-Yao/CSE598-Demo/tree/tool) | Lab 5: Tool Use | A small login service with a seeded bug. Watch a coding agent find and fix it with tools. |
| [`memory`](https://github.com/Hyan-Yao/CSE598-Demo/tree/memory) | Agent Memory | A gradebook repo and a rounding rule the user states once. Compare a later session with Codex memories off and on. |

Clone one branch:

```
git clone -b tool   https://github.com/Hyan-Yao/CSE598-Demo.git CSE598-ToolUse-Demo
git clone -b memory https://github.com/Hyan-Yao/CSE598-Demo.git CSE598-Memory-Demo
```
